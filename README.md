# 🚀 Focus Guard Pro — App Overview

**Focus Guard Pro** is a modern, professional Android app for parents and guardians to help children build healthy smartphone usage and study habits. It provides flexible app locking schedules, real-time parent control, and a beautiful, intuitive interface for both parent and child users.

## Core Features

### 1. Parent/Child Roles
- **Parent interface:** Full access to setup, controls, requests, device pairing, PIN management, and tamper protection.
- **Child interface:** Clean, minimal UI with only personal status and pending requests.

### 2. Device Pairing
- Quick pairing between parent and child devices via secure code or QR.
- All settings and controls sync instantly via the cloud (Firebase).

### 3. App Locker
- Parent can lock specific apps on the child device—apps are inaccessible during locked periods.
- Clean, searchable app picker UI.
- Real-time lock/unlock sync.

### 4. Flexible Scheduling
- Parents can design **complex, flexible study/break schedules** for every day of the week.
- Multiple study and break periods per day, with quick add/edit/remove.
- Schedules are synced and enforced on the child’s device.

### 5. Permission Requests
- Children may request access/unlock for specific apps or times.
- Parents see, review, and approve/reject requests in real time.

### 6. Security & Tamper Protection
- Admin PIN settings (parent only).
- Device Admin/accessibility reminders, so the app can’t be easily uninstalled or bypassed.
- Secure persistent rules.

### 7. Modern, Professional UI (Material 3)
- Clean, minimalist, dark and light theme support.
- Accent colors and intuitive navigation.
- Smooth transitions and clear visual hierarchy.

## Why Focus Guard Pro? (Benefits)
- **Non-intrusive:** Encourages healthy device habits, doesn’t spy.
- **Flexible:** Adapts to complex family schedules—not just “on/off.”
- **Empowering:** Lets kids earn trust and manage time with gentle guard rails.
- **Secure:** Cloud sync, PIN, and parental control features protect settings from tampering.

## Screens / Navigation (Parent view)
1. **Dashboard:** At-a-glance status, recent requests, sync status.
2. **Apps:** Select/lock/unlock apps.
3. **Requests:** Review and respond to child’s in-app requests.
4. **Schedule:** Fully customizable, add multiple intervals for every day.
5. **Settings:** Admin PIN, role, security, cloud, and device setup.

**Child view:** Minimal dashboard, status, send request, see schedule.

## Summary
Focus Guard Pro is a next-generation parental control app focused on respect, flexibility, and a professional experience. Parents get fine control and peace of mind; kids get clear guardrails and opportunities to build better focus—without frustration.
